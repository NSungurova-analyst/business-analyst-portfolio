# 📋 ТЗ: Запись на прием к врачу в частной клинике

## Бизнес-требование:

**Цель:** Автоматизировать запись к врачу через мобильное приложение

**Обоснование:** Пациент может сам записаться к врачу, не ожидая на телефонной линии оператора, а также самостоятельно выбрать параметры приёма (врача, дату, время, место)

**Метрики:**
- Сокращение времени записи с 10 минут до 2 минут
- Снижение нагрузки на операторов на 30%
- Рост количества записей на 20%

---

## User Story:

**Как** пациент клиники,
**я хочу** иметь возможность самостоятельно записаться к врачу через приложение,
**чтобы** я мог выбрать подходящего специалиста, удобное время и место приёма без звонка в регистратуру

---

## Фронтенд:

1. Кнопка "Запись" на главной (в нижнем меню)
2. Экран со списком специальностей + поиск + кнопки "Фильтры" и "Дата приёма"
3. При выборе специальности → экран с врачами:
   - Показывается выбранная дата (по умолчанию — сегодня)
   - Карточки врачей (ФИО, стаж, степень, услуга, стоимость, адрес, метро)
   - На каждой карточке: доступные временные слоты (кнопки)
4. При нажатии "Дата приёма" → модальное окно с календарём → выбор даты → кнопка "Применить"
5. При нажатии "Фильтры" → страница с параметрами (клиника, врач, степень, пол) → кнопка "Показать N врачей"
6. При нажатии на время (на карточке) → модальное окно подтверждения записи
7. В окне подтверждения: данные пациента, врача, адрес, дата, время, стоимость, подготовка
8. Кнопка "Записаться" → отобразить лоудер → отправить POST-запрос
9. Успех → модульное окно "Вы записаны на приём!" с деталями записи:
   - Данные пациента
   - Врач (ФИО, специализация, стаж, степень)
   - Стоимость
   - Дата и время
   - Адрес клиники + метро
   - Подготовка
   - Кнопки: "Перейти в Предстоящие приёмы" и "Записаться ещё"
10. Ошибка → уведомление "Не удалось записаться"
11. Раздел "Медкарта" → подраздел "Приёмы" (предстоящие, завершённые, отменённые)
12. GET-запрос для получения списка записей пациента
13. В предстоящих → карточка записи с кнопками "Перенести" / "Отменить"
14. При отмене → модальное окно подтверждения → PATCH-запрос
15. Успех → уведомление "Запись отменена" + обновление списка

---

## Бэкенд:

1. Создать таблицу для записей (сущность "Запись"), которая включает:
   - идентификатор
   - связь с клиентом
   - связь с врачом
   - дату и время
   - статус (предстоящий, завершённый, отменённый)
   - причину обращения
   - стоимость
   - дату создания

2. Реализовать **GET-запрос** для получения списка врачей (с возможностью фильтрации по специальности, клинике и дате)
3. Реализовать **GET-запрос** для получения списка записей пациента (с фильтрацией по статусам: предстоящие, завершённые, отменённые)
4. Реализовать **POST-запрос** для создания новой записи, в рамках которого будем принимать данные с фронта и сохранять запись в таблицу
5. Реализовать **PATCH-запрос** для отмены записи, в рамках которого будем менять статус записи на "отменён" и возвращать ответ (успешно/ошибка)
