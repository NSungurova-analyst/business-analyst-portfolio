# **ТЗ: Добавление нового раздела "Адреса" в приложение Самокат**

## **Бизнес-требование:**

**Цель:** упростить процесс заказа, ускорить оформление

**Обоснование:** пользователи часто заказывают на одни и те же адреса

**Метрики:** сокращение времени оформления заказа

## **User Story:**

**Как** пользователь приложения Самокат,
**я хочу** иметь возможность сохранять и управлять адресами доставки,
**чтобы** я мог быстро оформлять заказы без повторного ввода адреса


## **Фронтенд:**

1. Добавить раздел "Адреса" в меню приложения
2. При входе в раздел "Адреса" → отправить **GET запрос** на бэкенд для получения списка адресов
3. Отобразить список сохранённых адресов (карточками):
   - Адрес (улица, дом)
   - Кнопка "..." справа → при нажатии открывается страница редактирования с полями (Квартира, Подъезд, Этаж, Код домофона, Комментарий)
   - Кнопка "Удалить адрес" сверху на странице редактирования
4. Если адресов нет → показать пустое состояние "Нет сохранённых адресов"
5. Добавить кнопку "Новый адрес" внизу страницы
6. При нажатии "Новый адрес" → экран с картой
7. Запросить разрешение на геолокацию (модальное окно)
8. Если разрешил → показать адрес на карте + кнопки "Да, всё верно" и "Ввести другой адрес"
9. Если отказал → показать карту + кнопка "Ввести другой адрес"
10. При нажатии "Да, всё верно" → переход к странице оформления заказа (с базовым адресом)
11. При нажатии "Ввести другой адрес" → форма ручного ввода (город, улица, дом)
12. На странице оформления заказа → блок с выбранным адресом
13. При нажатии на адрес → переход к списку адресов (пункт 2)
14. После выбора адреса → возврат на оформление заказа с подставленным адресом
15. Кнопка "Продолжить" на странице оформления заказа → переход к странице детализации адреса
16. На странице детализации → поля (Квартира, Подъезд, Этаж, Код домофона, Комментарий)
17. Кнопка "Сохранить" / "Продолжить к оплате" → **POST запрос** на сохранение адреса с деталями
18. При сохранении отображать:
    - Лоудер во время сохранения
    - Успех → уведомление "Адрес сохранён" + переход к оплате
    - Ошибка → уведомление "Не удалось сохранить"

## **Бэкенд:**

1. Создать таблицу для адресов (сущность "адрес"), которая включает:
   - идентификатор адреса
   - связь с пользователем
   - основные поля (улица, дом, квартира, подъезд, этаж, код домофона, комментарий)
   - координаты (широта, долгота)
2. Реализовать **GET запрос** для получения списка адресов пользователя
3. Реализовать **POST запрос** для сохранения нового адреса, в рамках которого будем принимать данные с фронта, сохранять в таблицу и возвращать ответ (успешно сохранено/ошибка)
4. Реализовать **PUT запрос** для редактирования адреса (при нажатии на троеточие)
5. Реализовать **DELETE запрос** для удаления адреса, в рамках которого будем принимать запрос с фронта, удалять адрес и возвращать ответ (успешно удалено/ошибка)
